AI-Based Self-Healing Communication Network

Project Overview

The AI-Based Self-Healing Communication Network is designed to monitor network health, detect communication failures, and support automatic recovery using ESP32 nodes and Machine Learning.

Objectives

- Build a communication network using ESP32 nodes.
- Monitor network performance in real time.
- Detect potential communication failures.
- Support automatic rerouting and network recovery.
- Display network status through a dashboard.

Technologies Used

- ESP32
- Arduino IDE
- Machine Learning
- Python
- IoT
- Wokwi Simulator

Parameters Monitored

- Signal strength (RSSI)
- Network latency
- Packet loss
- Traffic load
- Node health

Project Files

- "sketch.ino" — ESP32 program
- "diagram.json" — Circuit and component configuration
- "libraries.txt" — Required libraries
- "wokwi-project.txt" — Project information

Expected Outcome

A communication network that monitors node health and helps maintain reliable data transmission when network problems occur.
